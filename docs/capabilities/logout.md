# Яндекс Аудитории: Отключить Аудитории — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Удаляет сохранённый токен доступа с диска — отключает вход, выполненный из диалога.

Техническое имя: `logout`

## Какую задачу решает

> Я хочу отключить Яндекс Аудитории.

Удаляет сохранённый токен Аудиторий с диска. После этого инструменты данных перестают работать, пока пользователь не подключится заново через `start_login` или пока оператор не задаст `YANDEX_AUDIENCE_TOKEN`.

## Когда использовать

Используйте эту возможность, когда пользователь просит отключить Яндекс Аудитории, хочет войти под другим аккаунтом Яндекса или передаёт машину другому человеку и не хочет оставлять на ней доступ.

## Что нужно передать

Параметров нет — инструмент вызывается без входных данных.

## Что вернёт

Объект с полями `removed` (был ли удалён сохранённый токен), `note` (пояснение) и `envTokenStillSet` — предупреждение, что токен из переменной окружения `YANDEX_AUDIENCE_TOKEN` продолжает действовать: его нужно убирать из конфигурации клиента вручную.

## Что изменится в Яндекс Аудиториях

Опасная операция для локального подключения: файл с сохранённым токеном удаляется безвозвратно, и вернуть доступ можно только новым входом. В самом аккаунте Яндекса ничего не меняется — выданное приложению разрешение остаётся активным, отозвать его можно в [Яндекс ID](https://id.yandex.ru/security).

## Пример запроса

> Отключи Яндекс Аудитории на этой машине. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Токен, заданный переменной окружения `YANDEX_AUDIENCE_TOKEN`, инструмент не трогает — сервер продолжит работать с ним и после `logout`. Удаление касается только этой машины: доступ приложения на стороне Яндекса не отзывается.
