# Яндекс Аудитории: Список сегментов — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Возвращает список сегментов Яндекс Аудиторий, доступных пользователю (все типы: uploading, metrika, appmetrica, lookalike, geo, pixel).

Техническое имя: `list_segments`

## Какую задачу решает

> Я хочу посмотреть сегментов.

Возвращает список сегментов Яндекс Аудиторий, доступных пользователю (все типы: uploading, metrika, appmetrica, lookalike, geo, pixel).

## Когда использовать

Используйте эту возможность, когда нужен результат «Список сегментов» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `limit` — **необязательно**. Сколько сегментов вернуть (по умолчанию 10000).
- `offset` — **необязательно**. Порядковый номер сегмента, с которого начать выдачу (первый — 0).
- `pixel` — **необязательно**. Идентификатор пикселя: вернуть только сегменты, созданные на его основе.

## Что вернёт

Возвращает список сегментов Яндекс Аудиторий, доступных пользователю (все типы: uploading, metrika, appmetrica, lookalike, geo, pixel). Ответ — {"segments": [...]}: у каждого сегмента id, name, type, status (uploaded | is_processed | processed | processing_failed | is_updated | few_data), create_time, owner и типоспецифичные поля (у файловых — content_type, hashed, item_quantity, matched_quantity и др.).

## Что изменится в Яндекс Аудиториях

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть сегментов в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Пагинация: limit (по умолчанию 10000) и offset; параметр pixel фильтрует по сегментам, созданным на основе указанного пикселя. Отдельного метода получения одного сегмента в API нет — фильтруйте этот список по id.

Доступ также зависит от прав токена, квот и ограничений исходного API.
