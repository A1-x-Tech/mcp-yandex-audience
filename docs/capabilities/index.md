# MCP-возможности Яндекс Аудиторий

Каталог содержит 20 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-yandex-audience`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Подключение

- [Статус подключения к Аудиториям](./auth-status.md) — Показывает, есть ли токен, откуда он взят (переменная окружения или сохранённый вход), когда истекает и где лежит файл с сохранёнными данными. **Воздействие:** только чтение.
- [Начать подключение Аудиторий](./start-login.md) — Первый шаг входа из диалога: возвращает ссылку на страницу Яндекс OAuth, по которой пользователь получает код подтверждения. **Воздействие:** только чтение.
- [Завершить подключение Аудиторий](./finish-login.md) — Второй шаг: обменивает код подтверждения на токен доступа, сохраняет его на диск (0600) и сразу проверяет живым запросом — без перезапуска клиента. **Воздействие:** изменяет данные.
- [Отключить Аудитории](./logout.md) — Удаляет сохранённый токен с диска; токен из переменной окружения не трогает. **Воздействие:** опасная операция.

## Доступ к сегментам

- [Выдать доступ к сегменту](./add-segment-grant.md) — Создаёт разрешение на управление сегментом для указанного логина Яндекса. **Воздействие:** изменяет данные.
- [Отозвать доступ к сегменту](./delete-segment-grant.md) — Удаляет разрешение на управление сегментом у указанного пользователя. **Воздействие:** опасная операция.
- [Список доступов к сегменту](./list-segment-grants.md) — Возвращает список разрешений на управление сегментом. **Воздействие:** только чтение.

## Сегменты

- [Сохранить загруженный сегмент](./confirm-segment.md) — Сохраняет сегмент, созданный из файла (второй шаг после upload_segment_file / upload_segment_csv_file): задаёт имя, тип содержимого и параметры хеширования. **Воздействие:** изменяет данные.
- [Создать lookalike-сегмент](./create-lookalike-segment.md) — Создаёт сегмент типа lookalike — пользователи, «похожие» по поведению в интернете на аудиторию исходного сегмента (lookalike_link). **Воздействие:** изменяет данные.
- [Создать сегмент на основе пикселя](./create-pixel-segment.md) — Создаёт сегмент типа pixel — пользователи, которых пиксель (pixel_id из list_pixels) видел за последние period_length дней (1..90). **Воздействие:** изменяет данные.
- [Удалить сегмент](./delete-segment.md) — Удаляет указанный сегмент Яндекс Аудиторий. **Воздействие:** опасная операция.
- [Список сегментов](./list-segments.md) — Возвращает список сегментов Яндекс Аудиторий, доступных пользователю (все типы: uploading, metrika, appmetrica, lookalike, geo, pixel). **Воздействие:** только чтение.
- [Переименовать сегмент](./rename-segment.md) — Изменяет сегмент. **Воздействие:** изменяет данные.
- [Загрузить CSV-файл сегмента (CRM-данные)](./upload-segment-csv-file.md) — Создаёт сегмент из CSV-файла с CRM-данными. **Воздействие:** изменяет данные.
- [Загрузить файл сегмента (device id / MAC / хеши)](./upload-segment-file.md) — Создаёт сегмент из TSV/TXT-файла с данными: идентификаторы устройств (IDFA/GAID), MAC-адреса или SHA256-хеши, по одной записи в строке; минимум 100 записей, до 1 ГБ, UTF-8. **Воздействие:** изменяет данные.

## Пиксели

- [Создать пиксель](./create-pixel.md) — Создаёт пиксель Яндекс Аудиторий с заданным именем. **Воздействие:** изменяет данные.
- [Удалить пиксель](./delete-pixel.md) — Удаляет указанный пиксель Яндекс Аудиторий. **Воздействие:** опасная операция.
- [Список пикселей](./list-pixels.md) — Возвращает список пикселей Яндекс Аудиторий пользователя. **Воздействие:** только чтение.
- [Переименовать пиксель](./update-pixel.md) — Изменяет указанный пиксель (в схеме изменения доступно только поле name — переименование). **Воздействие:** изменяет данные.

## Дополнительные методы API

- [Произвольный запрос к API Аудиторий](./raw-request.md) — Escape hatch: прямой вызов любого пути Yandex Audience API, для эндпоинтов без выделенного инструмента (например, PUT "v1/management/segment/{id}/reprocess" — пересчёт сегмента, или POST "v1/management/pixel/{id}/undelete" — восстановление пикселя). **Воздействие:** опасная операция.
