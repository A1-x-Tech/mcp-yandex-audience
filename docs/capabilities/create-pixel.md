# Яндекс Аудитории: Создать пиксель — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Создаёт пиксель Яндекс Аудиторий с заданным именем.

Техническое имя: `create_pixel`

## Какую задачу решает

> Я хочу создать пиксель.

Создаёт пиксель Яндекс Аудиторий с заданным именем.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать пиксель» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `name` — **обязательно**. Название пикселя.

## Что вернёт

В ответе — {"pixel": {...}} с полем url: код пикселя, который нужно вставить в рекламные материалы (баннеры), после чего на его основе можно строить сегменты инструментом create_pixel_segment.

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать пиксель в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
