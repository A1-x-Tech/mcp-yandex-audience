# Яндекс Аудитории: Произвольный запрос к API Аудиторий — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Escape hatch: прямой вызов любого пути Yandex Audience API, для эндпоинтов без выделенного инструмента (например, PUT "v1/management/segment/{id}/reprocess" — пересчёт сегмента, или POST "v1/management/pixel/{id}/undelete" — восстановление пикселя).

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Escape hatch: прямой вызов любого пути Yandex Audience API, для эндпоинтов без выделенного инструмента (например, PUT "v1/management/segment/{id}/reprocess" — пересчёт сегмента, или POST "v1/management/pixel/{id}/undelete" — восстановление пикселя).

## Когда использовать

Используйте эту возможность, когда нужен результат «Произвольный запрос к API Аудиторий» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Относительный путь API, например "v1/management/segments?limit=5".
- `method` — **необязательно**. HTTP-метод. По умолчанию GET (безопасный).
- `body` — **необязательно**. JSON-тело запроса (для POST/PUT).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Аудиториях

Исходный код помечает весь вызов «Произвольный запрос к API Аудиторий» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить дополнительный запрос к API в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Путь указывается относительно хоста API; query-параметры включайте прямо в path (например, "v1/management/segments?limit=5"). body отправляется как JSON для POST/PUT. Заголовок Authorization подставляется автоматически; путь на чужой хост будет отклонён.

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
