# Яндекс Аудитории: Начать подключение Аудиторий — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Первый шаг подключения аккаунта прямо из диалога — возвращает ссылку на страницу Яндекс OAuth, по которой пользователь входит и получает код подтверждения.

Техническое имя: `start_login`

## Какую задачу решает

> Я хочу подключить Яндекс Аудитории прямо из диалога.

Первый шаг подключения без правки конфигурации и без перезапуска клиента: инструмент возвращает ссылку на страницу Яндекс OAuth. Пользователь открывает её в браузере под аккаунтом Яндекса, которому принадлежат нужные сегменты (или которому они доверены), подтверждает доступ на чтение и изменение сегментов и получает код подтверждения для `finish_login`.

## Когда использовать

Используйте эту возможность, когда сервер сообщает, что Яндекс Аудитории не подключены, либо когда нужно переподключиться под другим аккаунтом Яндекса. Повторный вызов отменяет предыдущий запрос на подключение и выдаёт новую ссылку.

## Что нужно передать

Параметров нет — инструмент вызывается без входных данных.

## Что вернёт

Объект с полями `authorizeUrl` (ссылка на страницу Яндекс OAuth — покажите её пользователю целиком), `clientId` (OAuth-приложение, через которое идёт вход), `expiresInMinutes` (10 — срок жизни кода подтверждения) и `nextStep` (что делать дальше).

## Что изменится в Яндекс Аудиториях

Инструмент только читает данные или состояние подключения и не изменяет их: ссылка формируется локально, без обращения к сети, а вход происходит в браузере пользователя. Схема — OAuth с PKCE: секретная часть (`code_verifier`) не покидает процесс сервера, поэтому код из переписки бесполезен для постороннего.

## Пример запроса

> Подключи Яндекс Аудитории. Покажи мне ссылку для входа и скажи, что делать дальше.

## Возможные ошибки и ограничения

Код подтверждения одноразовый и живёт 10 минут — если пользователь не успел, вызовите инструмент заново. Вход нужно выполнять под аккаунтом Яндекса с доступом к нужным сегментам: чужие сегменты после подключения видны не будут. Ссылка запрашивает ровно два права — чтение и изменение сегментов Аудиторий.
