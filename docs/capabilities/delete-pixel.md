# Яндекс Аудитории: Удалить пиксель — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Удаляет указанный пиксель Яндекс Аудиторий.

Техническое имя: `delete_pixel`

## Какую задачу решает

> Я хочу удалить пиксель.

Удаляет указанный пиксель Яндекс Аудиторий.

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить пиксель» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `pixel_id` — **обязательно**. Идентификатор пикселя (id из list_pixels).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Аудиториях

Исходный код помечает весь вызов «Удалить пиксель» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить пиксель в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Успешный ответ — {"success": true}. В API существует метод восстановления удалённого пикселя (POST /v1/management/pixel/{id}/undelete) — при необходимости он доступен через raw_request.

Доступ также зависит от прав токена, квот и ограничений исходного API.
