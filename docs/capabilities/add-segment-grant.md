# Яндекс Аудитории: Выдать доступ к сегменту — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Создаёт разрешение на управление сегментом для указанного логина Яндекса.

Техническое имя: `add_segment_grant`

## Какую задачу решает

> Я хочу создать разрешение на управление сегментом для указанного логина Яндекса.

Создаёт разрешение на управление сегментом для указанного логина Яндекса.

## Когда использовать

Используйте эту возможность, когда нужен результат «Выдать доступ к сегменту» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `segment_id` — **обязательно**. Идентификатор сегмента (id из list_segments или из ответа создания).
- `user_login` — **обязательно**. Логин пользователя Яндекса, которому выдаётся доступ.
- `permission` — **обязательно**. Уровень доступа: edit (изменение) | view (просмотр).
- `comment` — **необязательно**. Комментарий к разрешению (до 255 символов).

## Что вернёт

Ответ — {"grant": {...}} (поле created_at заполняет сервер).

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать разрешение на управление сегментом для указанного логина Яндекса в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

permission: edit — редактирование и использование сегмента, view — только просмотр/использование.

Доступ также зависит от прав токена, квот и ограничений исходного API.
