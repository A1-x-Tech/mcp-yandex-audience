# Яндекс Аудитории: Удалить сегмент — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Удаляет указанный сегмент Яндекс Аудиторий.

Техническое имя: `delete_segment`

## Какую задачу решает

> Я хочу удалить сегмент.

Удаляет указанный сегмент Яндекс Аудиторий.

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить сегмент» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `segment_id` — **обязательно**. Идентификатор сегмента (id из list_segments или из ответа создания).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Аудиториях

Исходный код помечает весь вызов «Удалить сегмент» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить сегмент в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Операция необратима (метода восстановления сегмента в API нет). Успешный ответ — {"success": true}.

Доступ также зависит от прав токена, квот и ограничений исходного API.
