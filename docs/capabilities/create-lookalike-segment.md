# Яндекс Аудитории: Создать lookalike-сегмент — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Создаёт сегмент типа lookalike — пользователи, «похожие» по поведению в интернете на аудиторию исходного сегмента (lookalike_link).

Техническое имя: `create_lookalike_segment`

## Какую задачу решает

> Я хочу создать lookalike-сегмент.

Создаёт сегмент типа lookalike — пользователи, «похожие» по поведению в интернете на аудиторию исходного сегмента (lookalike_link).

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать lookalike-сегмент» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `name` — **обязательно**. Название сегмента.
- `lookalike_link` — **обязательно**. Идентификатор исходного сегмента, на который будут «похожи» пользователи.
- `lookalike_value` — **обязательно**. Степень «похожести»: 1 (точнее, уже) .. 5 (шире охват).
- `maintain_device_distribution` — **необязательно**. Сохранять распределение по типам устройств исходного сегмента (по умолчанию true).
- `maintain_geo_distribution` — **необязательно**. Сохранять распределение по городам исходного сегмента (по умолчанию true).

## Что вернёт

Ответ — {"segment": {...}}; сегмент обрабатывается асинхронно, статус смотрите через list_segments.

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать lookalike-сегмент в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

lookalike_value — степень похожести от 1 (максимальная точность, меньший охват) до 5 (максимальный охват). maintain_device_distribution / maintain_geo_distribution (по умолчанию true) сохраняют распределение по типам устройств и городам исходного сегмента. Квота: 10/мин, 100/час, 500/сутки.

Доступ также зависит от прав токена, квот и ограничений исходного API.
