# Яндекс Аудитории: Список доступов к сегменту — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Возвращает список разрешений на управление сегментом.

Техническое имя: `list_segment_grants`

## Какую задачу решает

> Я хочу посмотреть доступов к сегменту.

Возвращает список разрешений на управление сегментом.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список доступов к сегменту» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `segment_id` — **обязательно**. Идентификатор сегмента (id из list_segments или из ответа создания).

## Что вернёт

Возвращает список разрешений на управление сегментом. Ответ — {"grants": [...]}: у каждого разрешения user_login (логин пользователя), permission (edit — редактирование, view — просмотр), comment и created_at.

## Что изменится в Яндекс Аудиториях

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть доступов к сегменту в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
