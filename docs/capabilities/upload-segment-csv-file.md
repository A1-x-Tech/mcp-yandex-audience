# Яндекс Аудитории: Загрузить CSV-файл сегмента (CRM-данные) — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Создаёт сегмент из CSV-файла с CRM-данными.

Техническое имя: `upload_segment_csv_file`

## Какую задачу решает

> Я хочу загрузить CSV-файл сегмента (CRM-данные).

Создаёт сегмент из CSV-файла с CRM-данными.

## Когда использовать

Используйте эту возможность, когда нужен результат «Загрузить CSV-файл сегмента (CRM-данные)» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `file_path` — **необязательно**. Путь к локальному файлу с данными. Укажите либо file_path, либо content (ровно одно).
- `content` — **необязательно**. Содержимое файла строкой (для небольших сегментов). Укажите либо content, либо file_path (ровно одно).
- `file_name` — **необязательно**. Имя файла для загрузки. По умолчанию — имя из file_path или стандартное имя.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Загрузить CSV-файл сегмента (CRM-данные) в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Первая строка — заголовок: колонки email, phone, ext_id (или external_id) и произвольные дополнительные поля; минимум 100 записей, до 1 ГБ. Это первый шаг двухфазного создания: в ответе сегмент со статусом uploaded и его id — затем сегмент нужно сохранить инструментом confirm_segment (content_type: crm). Источник данных: file_path (путь к локальному файлу) или content (содержимое строкой) — ровно одно из двух. Квота на создание сегментов: 10/мин, 100/час, 500/сутки.

Доступ также зависит от прав токена, квот и ограничений исходного API.
