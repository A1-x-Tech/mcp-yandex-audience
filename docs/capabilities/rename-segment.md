# Яндекс Аудитории: Переименовать сегмент — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Изменяет сегмент.

Техническое имя: `rename_segment`

## Какую задачу решает

> Я хочу переименовать сегмент.

Изменяет сегмент.

## Когда использовать

Используйте эту возможность, когда нужен результат «Переименовать сегмент» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `segment_id` — **обязательно**. Идентификатор сегмента (id из list_segments или из ответа создания).
- `name` — **обязательно**. Новое название сегмента.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Переименовать сегмент в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

В схеме изменения доступно только поле name, так что фактически это переименование. Работает с сегментом любого типа; ответ — {"segment": {...}} с обновлёнными данными.

Доступ также зависит от прав токена, квот и ограничений исходного API.
