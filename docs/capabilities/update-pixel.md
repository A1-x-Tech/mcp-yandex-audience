# Яндекс Аудитории: Переименовать пиксель — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Аудиторий:** Изменяет указанный пиксель (в схеме изменения доступно только поле name — переименование).

Техническое имя: `update_pixel`

## Какую задачу решает

> Я хочу переименовать пиксель.

Изменяет указанный пиксель (в схеме изменения доступно только поле name — переименование).

## Когда использовать

Используйте эту возможность, когда нужен результат «Переименовать пиксель» без ручной работы в интерфейсе Яндекс Аудиторий. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `pixel_id` — **обязательно**. Идентификатор пикселя (id из list_pixels).
- `name` — **обязательно**. Новое название пикселя.

## Что вернёт

Ответ — {"pixel": {...}} с обновлёнными данными.

## Что изменится в Яндекс Аудиториях

Инструмент изменяет реальные данные Яндекс Аудиторий так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Переименовать пиксель в Яндекс Аудиториях. Если не хватает обязательных идентификаторов, сначала уточни их.
